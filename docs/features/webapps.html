Web Uygulamaları (Progressive Web Apps - PWA)

G-Browser ile herhangi bir web sitesini masaüstü uygulaması gibi çalıştırabilir, tarayıcı arayüzünden bağımsız temiz bir pencerede kullanabilirsiniz.

Web Uygulaması Nedir?

Web Uygulamaları (PWA), modern web sitelerinin bağımsız masaüstü yazılımları gibi davranmasını sağlayan teknolojidir. Bir siteyi Web Uygulaması olarak yüklediğinizde:

  • Bağımsız Pencere: Adres çubuğu veya sekme karmaşası olmadan, tıpkı yerel bir Windows uygulaması gibi kendi özel penceresinde çalışır.
  • Görev Çubuğu ve Başlat Menüsü: Uygulamayı Windows görev çubuğuna sabitleyebilir, Başlat menüsünden veya masaüstü kısayolundan anında açabilirsiniz.
  • Tarayıcı Motoru Güvencesi: Arka planda G-Browser motoru çalıştığı için reklam engelleyiciniz, çerez ayarlarınız ve güvenlik önlemleriniz Web Uygulamasında da geçerli kalır.

Web Uygulamaları Desteğini Etkinleştirme

PWA motorunu kullanmaya başlamak için:

  1. G-Browser Ayarlarına gidin ve Web Uygulamaları (PWA) bölümünü açın (about:preferences#pwa).
  2. "Web Uygulamalarını Etkinleştir" seçeneğini açık konuma getirin.
  3. Dilerseniz uygulama pencerelerinde gezinme araç çubuğunun (geri, ileri, yenile) gösterilip gösterilmeyeceğini de buradan belirleyebilirsiniz.

Bir Web Sitesi Uygulama Olarak Nasıl Yüklenir?

Desteklenen bir web sitesini (örneğin YouTube, Spotify, WhatsApp Web, Notion, Twitter vb.) açtığınızda:

  1. Adres çubuğunun en sağında "Uygulamayı Yükle" simgesi belirir.
  2. Simgeye tıkladığınızda kurulum onay penceresi açılır.
  3. "Yükle" butonuna bastığınızda site anında bağımsız pencereye taşınır ve sisteminize entegre edilir.
Tüm Siteler İçin Geçerli

Web sitesi resmi bir PWA manifesti sunmasa bile, G-Browser menüsünden (hamburger menü > Araçlar > "Bu Sayfayı Uygulama Olarak Yükle") herhangi bir sayfayı bağımsız pencereye dönüştürebilirsiniz.

Yüklü Web Uygulamalarını Yönetme ve Kaldırma

Daha önce yüklediğiniz tüm uygulamaları incelemek veya kaldırmak için:

  • Ayarlar > Web Uygulamaları sayfasına gidin.
  • Yüklü uygulamalar listesinden uygulamanın üzerine tıklayarak izinlerini denetleyin veya "Kaldır" butonuna basarak sistemden temizleyin.
