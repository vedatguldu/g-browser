G-Browser Destek & Katkı Merkezi

G-Browser bağımsız, gizlilik odaklı ve açık kaynaklı bir web tarayıcısıdır. Karşılaştığınız sorunları bildirebilir, fikirlerinizi paylaşabilir veya projeye doğrudan destek olabilirsiniz.

Sorun ve Hata Bildirimi (Bug Report)

G-Browser kullanırken bir sorunla karşılaştıysanız veya bir özelliğin beklendiği gibi çalışmadığını fark ettiyseniz, lütfen GitHub Issues üzerinden hata kaydı açın:

  1. G-Browser GitHub Sorun Takipçisi sayfasına gidin.
  2. "New Issue" butonuna tıklayın.
  3. Sorunu adım adım nasıl yeniden oluşturabileceğimizi, işletim sisteminizi ve tarayıcı sürümünüzü açıklayın.
  4. Varsa ekran görüntüsü veya hata konsolu çıktısı ekleyin.

Yeni Özellik Talepleri (Feature Requests)

G-Browser'da görmek istediğiniz yeni bir özellik veya işlev fikriniz mi var? Topluluk tartışmalarımıza katılabilir veya GitHub üzerinden özellik talebi oluşturabilirsiniz.
